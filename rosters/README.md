# Rosters Directory

Store team rosters as JSON files. Format:

```json
{
  "team_name": "Team Name",
  "team_year": 2026,
  "jerseys": {
    "1": "Player One",
    "2": "Player Two",
    "16": "Jersey Sixteen Player",
    "23": "Jersey Twenty-Three"
  }
}
```

Filename convention: `{team_name}-{year}.json`

Example: `ultimate-club-2026.json`
